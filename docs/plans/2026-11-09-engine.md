# The Live Engine on `cons1-pp-l3` Epoch 3: Implementation Plan (B16)

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan batch by batch.
> In `docs/plans/2026-10-26-dual-input-batches.md` this is batch **B16**. Its batches are E1 to E5
> below. It follows the close of the consistency line (B9 to B15, `docs/plans/2026-11-05-consistency-loss.md`
> and `2026-11-08-voice-d-teacher.md`). No training, no bar: this plan serves a checkpoint.

**Goal:** a pupil on a web page speaks into a microphone or types a turn at any moment, and the
trained model (`cons1-pp-l3`, epoch 3, the healthy weight-3 checkpoint replicated on two seeds)
answers in voice and text, live, from the box, through a sparks job. Before anyone talks to it, an
offline replay on the holdout proves the engine's own code path answers a typed turn and a spoken
turn, and measures the cost of a frame.

**Architecture:**
- One `Engine` (GPU) wraps moshi 0.2.13's `LMGen` streaming session plus one Mimi: `hear(pcm)` is
  Mimi encode, one LM step, Mimi decode; `type(tokens)` is the probe's forced burst (one token a frame
  with SINE on the pupil stream and SILENCE on moshi's own stream, then 6 PAD frames), stepped as fast
  as the GPU goes. The adapters load exactly as the side-by-side job loads them; `lm.dep_q = 8`; greedy.
- An aiohttp websocket server around it, in the same sparks job: raw int16 PCM both ways (no opus),
  a one-byte message kind, one session at a time, every session recorded (steps, both wavs, meta).
- One HTML page we own (mic via AudioWorklet at 24 kHz, a text box, moshi's words and voice).
- A sparks job cannot publish a port. The server binds inside the container; the box host reaches
  the container's bridge address directly; the laptop reaches it with `ssh -L`. The job ends at
  `--max-minutes` or on `sparks abort` (SIGTERM), saving the open session first.
- `--replay N` is the same `Engine` without the network: holdout dialogue, pupil turn 1 in voice A,
  moshi answers, pupil turn 2 typed or spoken, moshi's next words classified as the B1.5 probe did.

**Tech stack:** Python 3.12, PyTorch (bf16), moshi 0.2.13 (box only), aiohttp (new, pinned),
numpy, sphn (wav), sentencepiece, pytest (`-n auto`), ruff, mypy strict, uv, sparks queue, POSIX sh,
one HTML/JS page (Chrome).

### 0.2 Decisions (settled here; the executor does not reopen them)

**D1. The engine is a sparks job that serves from inside its container.**
- `dual.jobs.engine` binds `0.0.0.0:8998` in the container and prints the container's bridge
  address (`socket.gethostbyname(socket.gethostname())`) on its first log line, before the model
  loads, so `/health` answers during the load.
- The box host reaches `http://<container-ip>:8998/` directly on the bridge. The laptop reaches it
  with `ssh -N -L 8998:<container-ip>:8998 vlad@<box>` (`make tunnel ENGINE_IP=…`) and opens
  `http://localhost:8998/`, which is a secure context for the microphone.
- The job stops at `--max-minutes` (default 180) or on `sparks abort` (SIGTERM): the server shuts
  down, every open websocket closes, the session is saved. While it runs the queue is blocked; nothing
  else is planned for the GPU (the research line is closed).
- Rejected: a resident process started by hand (chalkboard's pattern) breaks `CLAUDE.md`'s rule;
  a sparks feature for ports is outside this repo. If the bridge address is unreachable from the host
  (GATE-2), that is Vlad's decision, not the executor's.

**D2. Raw PCM over a websocket, one kind byte; our own page.**
- Every message is binary: `kind` byte then payload. Client to server: `AUDIO` (1) int16 LE mono
  24 kHz PCM in any length, `TYPED` (3) UTF-8 words. Server to client: `READY` (0) JSON once the model
  streams, `AUDIO` (1) one 1920-sample frame of moshi's voice, `TEXT` (2) a word piece, `STATUS` (4)
  JSON counters.
- No opus: 24 kHz int16 is 384 kbit/s each way over an ssh tunnel on a LAN or tailnet; it removes a
  wasm encoder from the page and sphn's opus from the server. The kinds 0/1/2 match PersonaPlex's
  wire where they overlap.
- The page is `src/dual/client.html`, one file, no build step, served by the job at `GET /`.
  Mic through an `AudioWorklet` in an `AudioContext({sampleRate: 24000})`, int16 frames of 1920
  samples posted to the socket; playback by scheduling 80 ms `AudioBuffer`s back to back. Chrome.
  Headphones recommended: echo cancellation is on, but moshi's voice in the mic is otherwise a
  spoken pupil turn.

**D3. The typed turn is the probe's burst at the moment the words arrive.**
- `typed_tokens(words, spm.EncodeAsIds)` then `typed_segment(tokens)`: one token a frame with
  `SINE` on the pupil stream and `SILENCE` forced on moshi's own stream, then 6 `PAD` frames on the
  same codes. Stepped back to back; moshi's own codes on those frames are decoded and dropped so
  Mimi's decoder stays in step, and the page hears nothing until the first free frame.
- Mic frames that arrived while the pupil typed are discarded after the burst (the pupil was
  typing, not talking). The backlog rule (D4) then applies.
- A typed turn while moshi is mid-sentence cuts moshi off: the design doc's open point, left as it is.
- Rejected: TTS-voicing the typed text (chalkboard's engine): that is the conversion door, not the
  typed door this project built.

**D4. Real time by a backlog rule, not by skipping model steps.**
- The worker steps one mic frame per `hear`. If more than `MAX_BACKLOG` = 25 frames (2 s) are
  queued, the oldest are dropped down to `BACKLOG_KEEP` = 2 and counted in `dropped`. The design
  doc's 89 ms a frame on the GB10 is 11% over the 80 ms budget; the rule bounds the drift instead of
  hiding it. `STATUS` reports `hear_ms` and `dropped` every 25 frames so the page shows the truth.
- Default compiled (moshi's CUDA graphs), `--eager` opt-in. The replay (E4) measures both and picks.
- Rejected for now: folding the adapters into the weights (chalkboard's `fold_into`) to shave the
  LoRA matmuls. It is the first lever if the replay's hear step is over 160 ms (2× budget); then it
  is an opus task, not this plan.

**D5. The model is served in the measured condition.**
- Adapters as the side-by-side job loads them (wrappers, bf16), `lm.dep_q = 8`, temperatures 0
  (`--temp`, `--temp-text` exist for the GATE, default 0). No voice prompt, no frame-0 text prompt:
  every B10-B15 decode started a fresh session with neither, and that is what was judged healthy.
- `--bare` serves the base without adapters (a control for the GATE, not the default).

**D6. The replay check is the probe's scenario on the trained checkpoint through the live code path.**
- For each of the first N holdout stems (N = 13, all): decode pupil turn 1's voice-A codes to PCM
  once (Mimi, non-streaming), then feed those PCM frames through `engine.hear` exactly as the mic
  would; free frames of digital silence (`hear` on a zero frame) until 12 after `</s>` or 150; then
  turn 2 either `engine.type(tokens)` (its typed seg minus the 6 PAD) or `hear` on turn 2's voice-A
  PCM; then 150 free frames; `classify(words, free_ids, decode)`.
- Written: `runs/<name>/engine/replay.jsonl` (per stem × variant: class, emitted words, first
  answer, frame counts, timings) and `summary.json` (classes per variant, pooled `hear_ms` and
  `burst_ms`, compile mode, run, epoch).
- **Pre-registered reading (GATE-1):** go live if typed `answer` ≥ 11/13 and spoken `answer` ≥ 11/13
  and the compiled or eager run's mean `hear_ms` ≤ 160. A typed `echo` ≥ 3 is read (transcripts) before
  going live, not an automatic stop. `hear_ms` mean ≤ 100 is "real time with the backlog rule";
  100-160 goes live with the lag noted. Over 160 on both modes: stop, report to Vlad (D4's lever).
- Mode choice: compiled if it ran to the end; eager otherwise. If both ran, compiled unless eager's
  mean `hear_ms` is at least 10% lower.

**D7. Every live session is a record.**
- `runs/<name>/engine/<YYYYmmdd-HHMMSS>/`: `steps.jsonl` (one row a step: index, kind hear / typed /
  gap, text id, ms), `pupil.wav` (the mic as heard), `moshi.wav` (the voice as sent), `meta.json`
  (counters, typed turns with their frame index, timings, transcript, error if any).
- `make session NAME=… SESSION=…` copies one back under `runs/` for E5 to read.

```python
"""The live engine's pure parts: the wire, the mic frame buffer, the backlog rule,
the typed burst, the timings and the session record. No torch, no network.

The wire. Every websocket message is binary: one kind byte, then the payload.

    client -> server   AUDIO   int16 little-endian mono PCM at 24 kHz, any length
                       TYPED   the UTF-8 words of a typed pupil turn
    server -> client   READY   JSON once the model streams: {"session": name}
                       AUDIO   one 1920-sample frame of moshi's voice, int16 LE
                       TEXT    a UTF-8 word piece moshi emitted
                       STATUS  JSON counters, see Counters.status

The typed turn is PersonaPlex's prompt mechanism at any frame (the design doc,
section 1): one token a frame on the text stream, SILENCE on moshi's own audio, SINE
on the pupil stream, then GAP_FRAMES of PAD on the same codes. `typed_segment` in
frames.py is that triple; `burst` reads it out frame by frame for the GPU loop.
"""

from __future__ import annotations

import json
import time
from collections.abc import Sequence
from dataclasses import dataclass, field
from typing import Any

from dual.constants import FRAME_RATE
from dual.frames import typed_segment
from dual.probe_text import CLASSES

SAMPLE_RATE = 24000
FRAME_SAMPLES = int(SAMPLE_RATE / FRAME_RATE)  # 1920 samples, 80 ms
FRAME_BYTES = 2 * FRAME_SAMPLES  # int16

READY = 0
AUDIO = 1
TEXT = 2
TYPED = 3
STATUS = 4
KINDS = (READY, AUDIO, TEXT, TYPED, STATUS)

# Mic frames queued for the model. Past MAX_BACKLOG the oldest are dropped down to
# BACKLOG_KEEP: the model is behind real time (a typed burst, a slow step) and the
# pupil would hear every answer later and later. 25 frames is 2 s.
MAX_BACKLOG = 25
BACKLOG_KEEP = 2

SPECIALS = 4  # <unk> <s> </s> <pad>: no words
STATUS_EVERY = 25  # frames between STATUS messages

STEP_KINDS = ("hear", "typed", "gap")
REPLAY_VARIANTS = ("typed", "spoken")

Frame = tuple[int, tuple[int, ...], tuple[int, ...]]  # text, own 8, pupil 8


def pack(kind: int, payload: bytes = b"") -> bytes:
    if kind not in KINDS:
        raise ValueError(f"unknown message kind {kind}")
    return bytes([kind]) + payload


def unpack(message: bytes) -> tuple[int, bytes]:
    if not message:
        raise ValueError("empty message")
    kind = message[0]
    if kind not in KINDS:
        raise ValueError(f"unknown message kind {kind}")
    return kind, bytes(message[1:])


class PcmBuffer:
    """Mic bytes in any lengths, whole 1920-sample frames out."""

    def __init__(self) -> None:
        self._held = bytearray()

    @property
    def pending(self) -> int:
        """Bytes held back, short of a frame."""
        return len(self._held)

    def push(self, data: bytes) -> list[bytes]:
        if len(data) % 2:
            raise ValueError(f"{len(data)} bytes is not whole int16 samples")
        self._held.extend(data)
        out: list[bytes] = []
        while len(self._held) >= FRAME_BYTES:
            out.append(bytes(self._held[:FRAME_BYTES]))
            del self._held[:FRAME_BYTES]
        return out


def trim_backlog(
    queued: int, limit: int = MAX_BACKLOG, keep: int = BACKLOG_KEEP
) -> int:
    """How many of `queued` mic frames to drop: none within `limit`, else all but
    the newest `keep`."""
    if keep < 0 or limit < keep:
        raise ValueError(f"bad backlog rule: limit {limit}, keep {keep}")
    if queued <= limit:
        return 0
    return queued - keep
```

def typed_words(text: str) -> list[str]:
    words = text.split()
    if not words:

def burst(tokens: Sequence[int]) -> list[Frame]:
    """The typed turn frame by frame: (text, own, pupil) a step, tokens then the gap."""
    seg = typed_segment(tokens)
    return list(zip(seg.text, seg.own, seg.pupil, strict=True))


def is_word(token: int) -> bool:
    return token >= SPECIALS


def piece_text(piece: str) -> str:
    """A SentencePiece piece as the page shows it: the word boundary is a space."""
    return piece.replace("\u2581", " ")


@dataclass
class Timing:
    """Wall-clock milliseconds of one kind of step."""

    ms: list[float] = field(default_factory=list)

    def add(self, seconds: float) -> None:
        self.ms.append(1000.0 * seconds)

    def extend(self, other: Timing) -> None:
        self.ms.extend(other.ms)

    def summary(self) -> dict[str, float | int]:
        if not self.ms:
            return {"n": 0}
        s = sorted(self.ms)
        return {
            "n": len(s),
            "mean": sum(s) / len(s),
            "p50": s[len(s) // 2],
            "p90": s[min(len(s) - 1, (9 * len(s)) // 10)],
            "max": s[-1],
        }


@dataclass
class Counters:
    """What one session has done so far; `status` is the STATUS message of it."""

    frames: int = 0  # model steps
    heard: int = 0  # mic frames stepped
    typed: int = 0  # typed turns
    dropped: int = 0  # mic frames dropped: the backlog rule, or during a burst
    hear: Timing = field(default_factory=Timing)
    burst: Timing = field(default_factory=Timing)

    def status(self) -> bytes:
        body = {
            "frames": self.frames,
            "heard": self.heard,
            "typed": self.typed,
            "dropped": self.dropped,
            "hear_ms": self.hear.summary(),
            "burst_ms": self.burst.summary(),
        }
        return pack(STATUS, json.dumps(body).encode())


def step_row(index: int, kind: str, text: int, ms: float) -> dict[str, Any]:
    """One line of steps.jsonl: what the model said at step `index` and what the
    step cost. `kind`: "hear" (a mic frame), "typed" (a forced token), "gap" (a
    forced PAD). The audio of both sides is in the session's wavs."""
    if kind not in STEP_KINDS:
        raise ValueError(f"unknown step kind {kind!r}")
    return {"i": index, "kind": kind, "text": int(text), "ms": round(ms, 2)}


def session_name(now: float | None = None) -> str:
    stamp = time.time() if now is None else now
    return time.strftime("%Y%m%d-%H%M%S", time.gmtime(stamp))


def replay_summary(rows: Sequence[dict[str, Any]]) -> dict[str, Any]:
    """Per variant, the probe's classes counted over the replayed dialogues."""
    classes: dict[str, dict[str, int]] = {
        v: dict.fromkeys(CLASSES, 0) for v in REPLAY_VARIANTS
    }
    for r in rows:
        if r["variant"] not in classes:
            raise ValueError(f"unknown replay variant {r['variant']!r}")
        classes[r["variant"]][r["class"]] += 1
    return {"dialogues": len({r["stem"] for r in rows}), "classes": classes}

  for (let i = 0; i < f32.length; i++) {

const WORKLET = `
class Capture extends AudioWorkletProcessor {
  constructor() { super(); this.parts = []; this.n = 0; }
  process(inputs) {
    const ch = inputs[0] && inputs[0][0];
    if (!ch) return true;
    this.parts.push(new Float32Array(ch));
    this.n += ch.length;
    if (this.n >= ${FRAME}) {

      let o = 0;
      for (const p of this.parts) { out.set(p, o); o += p.length; }
      this.port.postMessage(out, [out.buffer]);
      this.parts = []; this.n = 0;
    }
    return true;
  }
}

function play(bytes) {
  if (!ctx) return;
  const n = bytes.byteLength >> 1;
  const i16 = new Int16Array(bytes.buffer.slice(bytes.byteOffset, bytes.byteOffset + 2 * n));
  const buf = ctx.createBuffer(1, n, RATE);
  const ch = buf.getChannelData(0);
  for (let i = 0; i < n; i++) ch[i] = i16[i] / FULL_SCALE;
  const src = ctx.createBufferSource();
  src.buffer = buf;
  src.connect(ctx.destination);
  const now = ctx.currentTime;
  if (playAt < now + 0.05) playAt = now + 0.05;  // a little headroom, then back to back
  src.start(playAt);
  playAt += buf.duration;
}

  const kind = data[0], payload = data.subarray(1);
  if (kind === AUDIO) play(payload);
  else if (kind === TEXT) say('moshi', dec.decode(payload));
  else if (kind === STATUS) setStatus(JSON.parse(dec.decode(payload)));
  else if (kind === READY) { say('note', 'model streaming: session ' + JSON.parse(dec.decode(payload)).session); setStatus('ready'); }

}

def _col(codes: Sequence[int], device: str) -> torch.Tensor:
    return torch.tensor(list(codes), dtype=torch.long, device=device).view(1, -1, 1)


def pcm_to_tensor(pcm: bytes, device: str) -> torch.Tensor:
    """int16 LE bytes of one frame -> [1, 1, 1920] float32 in [-1, 1] on `device`."""
    if len(pcm) != FRAME_BYTES:
        raise ValueError(f"{len(pcm)} bytes is not one frame of {FRAME_BYTES}")
    samples = np.frombuffer(pcm, dtype="<i2").astype(np.float32) / FULL_SCALE
    return torch.from_numpy(samples).clamp(-1.0, 1.0).view(1, 1, -1).to(device)


def tensor_to_pcm(pcm: torch.Tensor) -> bytes:
    """[1, 1, N] float -> int16 LE bytes."""
    out = (pcm[0, 0].float().clamp(-1.0, 1.0) * FULL_SCALE).round().to(torch.int16)
    return out.cpu().numpy().astype("<i2").tobytes()


def wav_of(frames: Sequence[bytes]) -> Any:
    """Frames of int16 LE bytes -> one float32 mono array (sphn.write_wav's input)."""
    if not frames:
        return np.zeros(0, dtype=np.float32)
    return np.frombuffer(b"".join(frames), dtype="<i2").astype(np.float32) / FULL_SCALE

class Engine:
    """One streaming model with Mimi in and out. One thread drives it at a time; the
    thread that calls open() must be the one that steps (torch.no_grad is per thread).
    """

    def __init__(
        self, base: Any, mimi: Any, device: str, temp: float, temp_text: float
    ) -> None:
        from moshi.models.lm import LMGen

        self.base, self.mimi, self.device = base, mimi, device
        self.forced: int | None = None
        self.last_text: int = PAD
        self.lm_gen = LMGen(
            base.lm,
            use_sampling=temp > 0 or temp_text > 0,
            temp=temp,
            temp_text=temp_text,
            on_text_hook=self._hook,
        )
        self.quiet = _col(MIMI_SILENCE, device)
        self._stack: contextlib.ExitStack | None = None
        self.counters = Counters()

    def _hook(self, text_token: torch.Tensor) -> None:
        # [B] view of the sampled token, before LMGen writes it to its cache.
        if self.forced is not None:
            text_token.copy_(torch.full_like(text_token, self.forced))
        self.last_text = int(text_token[0].item())

    @property
    def is_open(self) -> bool:
        return self._stack is not None

    def open(self) -> None:
        """A fresh session: moshi's and Mimi's streaming states, no gradients."""
        if self._stack is not None:
            raise RuntimeError("a session is already open")
        stack = contextlib.ExitStack()
        stack.enter_context(torch.no_grad())
        stack.enter_context(self.mimi.streaming(1))
        stack.enter_context(self.lm_gen.streaming(1))
        self._stack = stack
        self.counters = Counters()
        self.last_text = PAD

    def close(self) -> None:
        if self._stack is not None:
            self._stack.close()
            self._stack = None

    def step_codes(
        self,
        pupil: torch.Tensor,
        forced: int | None = None,
        own: torch.Tensor | None = None,
    ) -> tuple[int, torch.Tensor | None]:
        """One frame: the pupil's 8 codes [1, 8, 1] in; moshi's text id out and, once
        the delays are filled, its 8 own codes [1, 8, 1] (None before that)."""
        if self._stack is None:
            raise RuntimeError("open() first")
        self.forced = forced
        out = self.lm_gen.step(pupil, depformer_replace_tokens=own)
        self.forced = None
        self.counters.frames += 1
        if out is None:
            return self.last_text, None
        codes = out[:, 1:, :]
        if not bool((codes >= 0).all()):
            return self.last_text, None
        return self.last_text, codes

    def decode(self, own: torch.Tensor) -> bytes:
        return tensor_to_pcm(self.mimi.decode(own))

    def hear(self, pcm: bytes) -> tuple[int, bytes | None]:
        """A mic frame in; moshi's text id and its voice frame (or None) out."""
        t0 = time.monotonic()
        codes = self.mimi.encode(pcm_to_tensor(pcm, self.device))
        text, own = self.step_codes(codes)
        voice = None if own is None else self.decode(own)
        self.counters.hear.add(time.monotonic() - t0)
        self.counters.heard += 1
        return text, voice

    def type(self, tokens: Sequence[int]) -> list[int]:
        """The typed burst, as fast as the GPU steps: one token a frame on SINE with
        moshi's own audio forced to SILENCE, then GAP_FRAMES of PAD. Returns the text
        ids as forced. The forced frames are decoded and dropped so Mimi's decoder
        stays in step; the page hears nothing until the first free frame."""
        t0 = time.monotonic()
        ids: list[int] = []
        for text, own, pupil in burst(tokens):
            got, codes = self.step_codes(
                _col(pupil, self.device), forced=int(text), own=_col(own, self.device)
            )
            if codes is not None:
                self.mimi.decode(codes)
            ids.append(got)
        self.counters.burst.add(time.monotonic() - t0)
        self.counters.typed += 1
        return ids

    def warmup(self) -> None:
        """A throwaway session that captures moshi's CUDA graphs and Mimi's."""
        self.open()
        try:
            for _ in range(WARMUP_FRAMES):
                _, own = self.step_codes(self.quiet)
                if own is not None:
                    self.decode(own)
            self.hear(ZERO_FRAME)
        finally:
            self.close()


def pcm_frames_of(mimi: Any, codes: Sequence[Sequence[int]], device: str) -> list[bytes]:
    """A voiced pupil turn's Mimi codes -> its PCM, one frame of int16 bytes per code
    frame, decoded in one non-streaming pass (outside any session)."""
    with torch.no_grad():
        t = torch.tensor(codes, dtype=torch.long, device=device).t()[None]  # [1, 8, T]
        pcm = mimi.decode(t)  # [1, 1, T * 1920]
    total = pcm.shape[-1] // FRAME_SAMPLES
    return [
        tensor_to_pcm(pcm[:, :, i * FRAME_SAMPLES : (i + 1) * FRAME_SAMPLES])
        for i in range(total)
    ]


def replay(args: argparse.Namespace, engine: Engine, spm: Any, out: pathlib.Path) -> None:
    """The B1.5 probe's scenario on this checkpoint through the live path (D6)."""
    path = pathlib.Path.cwd() / "runs" / args.render / "render" / "holdout.jsonl"
    records = [json.loads(ln) for ln in path.read_text().splitlines() if ln.strip()]
    chosen = records[: args.replay]
    print(f"replay: {len(chosen)} of {len(records)} holdout dialogues from {path}")

    def decode(ids: list[int]) -> str:
        return str(spm.DecodeIds([int(i) for i in ids]))

    rows: list[dict[str, Any]] = []
    hear_all, burst_all = Timing(), Timing()
    for rec in chosen:
        turns = [int(k) for k in rec["pupil_turns"]]
        if len(turns) < 2:
            print(f"{rec['id']}: fewer than two pupil turns, skipped")
            continue
        first = pcm_frames_of(
            engine.mimi, rec["renderings"][str(turns[0])]["A"]["pupil"], engine.device
        )
        second = rec["renderings"][str(turns[1])]
        tokens = [int(t) for t in second["typed"]["text"][: -GAP_FRAMES]]
        words = words_of(decode(content_ids(tokens)))
        second_pcm = pcm_frames_of(engine.mimi, second["A"]["pupil"], engine.device)
        for variant in ("typed", "spoken"):
            engine.open()
            try:
                t0 = time.monotonic()
                heard: list[int] = []
                for pcm in first:
                    text, _ = engine.hear(pcm)
                    heard.append(text)
                answer: list[int] = []
                end_at: int | None = None
                for i in range(FREE_FRAMES):
                    text, _ = engine.hear(ZERO_FRAME)
                    answer.append(text)
                    if end_at is None and text == END:
                        end_at = i
                    if end_at is not None and i >= end_at + AFTER_END:
                        break
                typed_at = engine.counters.frames
                if variant == "typed":
                    engine.type(tokens)
                else:
                    for pcm in second_pcm:
                        engine.hear(pcm)
                free_at = engine.counters.frames
                free: list[int] = []
                for _ in range(FREE_FRAMES):
                    text, _ = engine.hear(ZERO_FRAME)
                    free.append(text)
                verdict = classify(words, free, decode)
                c = engine.counters
                hear_all.extend(c.hear)
                burst_all.extend(c.burst)
                row = {
                    "stem": rec["id"],
                    "variant": variant,
                    "class": verdict,
                    "typed_words": words,
                    "first_answer": decode(content_ids(answer)),
                    "emitted": decode(content_ids(free)),
                    "emitted_ids": free,
                    "frames": {
                        "spoken_1": len(first),
                        "answer_1": len(answer),
                        "turn_2": free_at - typed_at,
                        "free": len(free),
                        "free_pieces": len(content_ids(free)),
                    },
                    "hear_ms": c.hear.summary(),
                    "burst_ms": c.burst.summary(),
                    "seconds": time.monotonic() - t0,
                }
                rows.append(row)
                print(
                    f"{rec['id']} {variant}: {verdict} in {row['seconds']:.0f}s | "
                    f"hear {c.hear.summary().get('mean', 0):.0f} ms | typed: "
                    f"{' '.join(words)!r} | emitted: {row['emitted']!r}"
                )
            finally:
                engine.close()
    with (out / "replay.jsonl").open("w") as f:
        for row in rows:
            f.write(json.dumps(row) + "\n")
    summary = {
        **replay_summary(rows),
        "hear_ms": hear_all.summary(),
        "burst_ms": burst_all.summary(),
        "compile": not args.eager,
        "bare": args.bare,
        "run": None if args.bare else args.run,
        "epoch": None if args.bare else args.epoch,
        "temp": [args.temp, args.temp_text],
    }
    (out / "summary.json").write_text(json.dumps(summary, indent=2))
    print("summary:", json.dumps(summary))

class Session:
    """One websocket's model session. The worker thread steps the model; the asyncio
    side feeds it mic frames and typed turns and sends what it posts to `outbox`."""

    def __init__(
        self, engine: Any, spm: Any, out: pathlib.Path, loop: asyncio.AbstractEventLoop
    ) -> None:
        self.engine, self.spm, self.loop = engine, spm, loop
        self.name = session_name()
        self.dir = out / self.name
        self.inbox: queue.Queue[tuple[str, Any]] = queue.Queue()
        self.outbox: asyncio.Queue[bytes | None] = asyncio.Queue()
        self.buffer = PcmBuffer()
        self.steps: list[dict[str, Any]] = []
        self.heard: list[bytes] = []
        self.voiced: list[bytes] = []
        self.typed_log: list[dict[str, Any]] = []
        self.error: str | None = None

    # the asyncio side
    def feed(self, data: bytes) -> None:
        kind, payload = unpack(data)
        if kind == AUDIO:
            for frame in self.buffer.push(payload):
                self.inbox.put(("hear", frame))
        elif kind == TYPED:
            self.inbox.put(("type", payload.decode("utf-8")))
        else:
            raise ValueError(f"the page sent a server-only kind {kind}")

    def stop(self) -> None:
        self.inbox.put(("stop", None))

    # the worker side
    def post(self, message: bytes | None) -> None:
        self.loop.call_soon_threadsafe(self.outbox.put_nowait, message)

    def run(self) -> None:
        try:
            self.engine.open()
            self.post(pack(READY, json.dumps({"session": self.name}).encode()))
            while True:
                cmd, arg = self.inbox.get()
                if cmd == "stop":
                    break
                if cmd == "type":
                    self.handle_typed(str(arg))
                else:
                    self.handle_hear(bytes(arg))
        except Exception as e:  # broad on purpose: the record must say why it died
            self.error = repr(e)
            print("session error:", self.error, flush=True)
        finally:
            self.engine.close()
            self.post(None)

    def queued_hears(self) -> int:
        """Mic frames waiting, not counting a typed turn or the stop."""
        with self.inbox.mutex:  # the asyncio side appends under the same lock
            return sum(1 for cmd, _ in self.inbox.queue if cmd == "hear")

    def drop_hears(self, n: int) -> int:
        """Drops up to `n` queued mic frames from the front, never a typed turn."""
        dropped = 0
        q = self.inbox.queue  # the worker is the only consumer; a peek is atomic
        while dropped < n and q and q[0][0] == "hear":
            self.inbox.get_nowait()
            dropped += 1
        self.engine.counters.dropped += dropped
        return dropped

    def handle_hear(self, frame: bytes) -> None:
        self.drop_hears(trim_backlog(self.queued_hears()))
        t0 = time.monotonic()
        text, voice = self.engine.hear(frame)
        ms = 1000 * (time.monotonic() - t0)
        self.heard.append(frame)
        c = self.engine.counters
        self.steps.append(step_row(c.frames, "hear", text, ms))
        if voice is not None:
            self.voiced.append(voice)
            self.post(pack(AUDIO, voice))
        if is_word(text):
            self.post(pack(TEXT, piece_text(self.spm.IdToPiece(text)).encode()))
        if c.frames % STATUS_EVERY == 0:
            self.post(c.status())

    def handle_typed(self, text: str) -> None:
        words = typed_words(text)
        tokens = typed_tokens(words, self.spm.EncodeAsIds)
        at = self.engine.counters.frames
        t0 = time.monotonic()
        ids = self.engine.type(tokens)
        secs = time.monotonic() - t0
        dropped = self.drop_hears(self.inbox.qsize())  # the mic while the pupil typed
        each = 1000 * secs / len(ids)
        for i, t in enumerate(ids):
            kind = "typed" if i < len(tokens) else "gap"
            self.steps.append(step_row(at + 1 + i, kind, t, each))
        self.typed_log.append(
            {
                "at": at,
                "words": words,
                "tokens": tokens,
                "seconds": secs,
                "dropped": dropped,
            }
        )
        self.post(self.engine.counters.status())
        print(
            f"typed at {at}: {' '.join(words)!r}, {len(tokens)} tokens in {secs:.2f}s, "
            f"dropped {dropped} mic frames",
            flush=True,
        )

    def save(self) -> None:
        import sphn  # type: ignore[import-untyped]

        self.dir.mkdir(parents=True, exist_ok=True)
        with (self.dir / "steps.jsonl").open("w") as f:
            for row in self.steps:
                f.write(json.dumps(row) + "\n")
        sphn.write_wav(str(self.dir / "pupil.wav"), wav_of(self.heard), SAMPLE_RATE)
        sphn.write_wav(str(self.dir / "moshi.wav"), wav_of(self.voiced), SAMPLE_RATE)
        c = self.engine.counters
        said = [int(r["text"]) for r in self.steps if r["kind"] == "hear"]
        meta = {
            "session": self.name,
            "frames": c.frames,
            "heard": c.heard,
            "dropped": c.dropped,
            "typed": self.typed_log,
            "hear_ms": c.hear.summary(),
            "burst_ms": c.burst.summary(),
            "transcript": str(self.spm.DecodeIds(content_ids(said))),
            "error": self.error,
        }
        (self.dir / "meta.json").write_text(json.dumps(meta, indent=1))
        print("saved", self.dir, flush=True)


async def pump(session: Session, ws: web.WebSocketResponse) -> None:
    """Sends what the worker posts; a None closes the socket (the session ended)."""
    while True:
        message = await session.outbox.get()
        if message is None:
            if not ws.closed:
                await ws.close()
            return
        if not ws.closed:
            await ws.send_bytes(message)


async def page(request: web.Request) -> web.StreamResponse:
    return web.FileResponse(CLIENT)


async def health(request: web.Request) -> web.Response:
    s = request.app[STATE]
    return web.json_response(
        {
            "ok": True,
            "name": s["name"],
            "ready": s["engine"] is not None,
            "busy": s["lock"].locked(),
            "sessions": s["sessions"],
        }
    )


async def websocket(request: web.Request) -> web.StreamResponse:
    s = request.app[STATE]
    if s["engine"] is None:
        raise web.HTTPServiceUnavailable(text="the model is still loading")
    if s["lock"].locked():
        raise web.HTTPConflict(text="a session is open; one at a time")
    async with s["lock"]:
        ws = web.WebSocketResponse(max_msg_size=4 * 2**20)
        await ws.prepare(request)
        session = Session(s["engine"], s["spm"], s["out"], asyncio.get_running_loop())
        worker = threading.Thread(target=session.run, name="engine", daemon=True)
        worker.start()
        sender = asyncio.create_task(pump(session, ws))
        try:
            async for msg in ws:
                if msg.type == web.WSMsgType.BINARY:
                    session.feed(msg.data)
                elif msg.type == web.WSMsgType.ERROR:
                    break
        finally:
            session.stop()
            await asyncio.to_thread(worker.join, 60)
            await sender
            session.save()
            s["sessions"] += 1
        return ws


def make_app(state: dict[str, Any]) -> web.Application:
    app = web.Application()
    app[STATE] = state
    app.router.add_get("/", page)
    app.router.add_get("/health", health)
    app.router.add_get("/ws", websocket)
    return app


def new_state(name: str, out: pathlib.Path) -> dict[str, Any]:
    return {
        "name": name,
        "out": out,
        "engine": None,
        "spm": None,
        "lock": asyncio.Lock(),
        "sessions": 0,
    }


async def serve(args: argparse.Namespace, out: pathlib.Path) -> None:
    state = new_state(args.name, out)
    runner = web.AppRunner(make_app(state), shutdown_timeout=90.0)
    await runner.setup()
    await web.TCPSite(runner, args.host, args.port).start()
    ip = socket.gethostbyname(socket.gethostname())
    print(
        f"engine: listening on {args.host}:{args.port}; container address {ip}; "
        f"page http://{ip}:{args.port}/ health http://{ip}:{args.port}/health",
        flush=True,
    )
    base, mimi = await asyncio.to_thread(load_model, args)
    engine = Engine(base, mimi, "cuda", args.temp, args.temp_text)
    await asyncio.to_thread(engine.warmup)
    state["engine"], state["spm"] = engine, base.spm
    print(f"engine: ready; stops after {args.max_minutes:g} min or SIGTERM", flush=True)
    stop = asyncio.Event()
    loop = asyncio.get_running_loop()
    for sig in (signal.SIGTERM, signal.SIGINT):
        loop.add_signal_handler(sig, stop.set)
    with contextlib.suppress(TimeoutError):
        await asyncio.wait_for(stop.wait(), timeout=60 * args.max_minutes)
    print(
        "engine: stopping" + (" (signal)" if stop.is_set() else " (max minutes)"),
        flush=True,
    )
    await runner.cleanup()  # closes open websockets: their handlers save the session
    print(f"engine: done, {state['sessions']} session(s) recorded", flush=True)


def main() -> None:
    args = parse_args()
    from dual.model import cap_gpu_memory, set_compile_mode

    set_compile_mode(args.eager)  # before anything imports moshi
    cap_gpu_memory(args.mem_cap_gib)

        replay(args, engine, base.spm, out)
    else:

    print("engine job ok")


if __name__ == "__main__":
    main()

class FakeEngine:
    """Engine's surface for the session tests: no torch work, deterministic."""

    def __init__(self):
        self.counters = Counters()
        self.opened = 0
        self.closed = 0
        self.typed: list[list[int]] = []

    def open(self):
        self.opened += 1
        self.counters = Counters()

    def close(self):
        self.closed += 1

    def hear(self, frame):
        self.counters.frames += 1
        self.counters.heard += 1
        self.counters.hear.add(0.01)
        # a word every third frame; a voice frame from the second on
        text = 100 + self.counters.frames if self.counters.frames % 3 == 0 else PAD
        voice = None if self.counters.frames < 2 else bytes([self.counters.frames % 256]) * FRAME_BYTES
        return text, voice

    def type(self, tokens):
        self.typed.append(list(tokens))
        ids = list(tokens) + [PAD] * GAP_FRAMES
        self.counters.frames += len(ids)
        self.counters.typed += 1
        self.counters.burst.add(0.05)
        return ids

## Appendix: what this plan could not settle (for the GATEs, not for the executor)

- **Host → container reachability.** Docker's default bridge lets the host reach a container's
  address unless the box's iptables or Docker daemon config says otherwise. Not verified on this box;
  GATE-2 verifies it before the model loads. The fallbacks are Vlad's.
- **Frame cost.** The design doc's 89 ms per frame on the GB10 was moshiko through chalkboard's
  loop; this engine adds Mimi encode in the same thread and the LoRA wrappers' matmuls. GATE-1
  measures it. D4's backlog rule keeps the demo honest if it is over 80 ms.
- **CUDA graphs with the LoRA wrappers and the text hook.** The probe ran compiled with the hook on
  the bare base; the side-by-side ran eager with the wrappers. Compiled with both is new; the replay
  runs both modes so a failure of one is a line in a log, not a dead demo.
- **The mic.** `AudioContext({sampleRate: 24000})` is honoured by Chrome; Safari may refuse it. The
  plan says Chrome. Echo cancellation is the browser's; headphones make it moot.
- **The replay's free frames are digital silence**, Mimi-encoded; a live room is not. The spoken
  replay variant decodes voice-A codes to PCM and re-encodes them, which is the mic's path but not a
  real microphone. The live session is the only test of either.
